# ELITE: NEXT radio source pack

These are optional CC0 source tracks selected for the radio decoder pass. The
current PSP runtime uses the deterministic integer synth in `src/radio-synth.h`
so the binary stays small and streams without a file decoder; this manifest
keeps the source and license trail ready for the streamed-radio pass.

- **Magic Space** — CodeManu — CC0 — https://opengameart.org/content/magic-space
  Source: `https://opengameart.org/sites/default/files/magic%20space.mp3`
- **Persistence (loop short)** — cinameng — CC0 — https://opengameart.org/content/persistence
  Source: `https://opengameart.org/sites/default/files/persistence-loopshort_1.mp3`
- **Floating in Space** — Umplix — CC0 — https://opengameart.org/content/floating-in-space
  Source: `https://opengameart.org/sites/default/files/empty_space.wav`

The in-game Far Horizons station adds a restrained alien chatter texture to
the procedural mix now. It is intentionally non-verbal and does not imitate a
real language; future streamed tracks can replace the station bed without
changing save data or station preferences.
