# Staged mission catalogue

Forty authored contracts; each line below is a successive objective.

## 1. Convoy Escort

**Contact:** CAPTAIN ORLA

1. Find and hail the convoy leader within 600 m.
2. Defeat the attackers. Protect the civilian ships.
3. Stay with the convoy until all surviving ships reach their destination.
4. Return to the commissioning station with your report.
