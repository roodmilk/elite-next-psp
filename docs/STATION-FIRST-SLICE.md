# Lave station reference build — 2.5.182

## Current playable loop

Dock at **Lave primary hub**, choose FLY > DISEMBARK. Up/Down highlights a person, doorway or prop and moves the glowing artwork outline. Cross explicitly inspects, speaks or uses the selection. Entering a room opens its description; hovering never replaces the last committed paragraph. Left/Right pages through persistent full-width text. Conversation replies appear on the right, selected with Up/Down and Cross. Triangle returns to the ship (or closes dialogue); Circle closes a conversation/service screen before leaving. Select opens the Berth Six objective. All prompts are at the bottom edge. The Chandler browse screen replaces the right rail with the actual deck stock, with matching selection and wraparound controls.

1. Arrivals: Venn directs the pilot to Mara.
2. Cargo: accept Mara's missing medicine-manifest job; inspect MANIFEST.
3. Canteen: Niko explains a coolant leak forced the crate to move.
4. Chandlery: Ada supplies a replacement seal.
5. Clinic: Dr Sen verifies the medicine lot.
6. Customs: Orin stamps clearance.
7. Cargo: hand the paperwork to Mara for **60 U**, once.
8. Guild: accept Iona's **90 U** follow-up; scan life or minerals on **Lave I**, then return. Existing Lave I records count. Other worlds do not.
9. Completed dialogue and objective remain available; no repeated payout.

Local job board, outfitting, legal status, treatment and jukebox are linked from appropriate rooms. Routine ship menus remain accessible without exploration. Services use the existing navigation stack, returning to the room with Circle. This is point-and-click room exploration, not a new free-walking engine.

## Art / procedural contract

- Concept and seven room sources: assets/source/lave-station/.
- Built-in image-generation tool used for concept, seven separate plates, transparent eight-object prop atlas and eight-person crew atlas. Prompt record: PROMPTS.md in that source directory.
- Native exports: assets/generated/lave-station/. Compiler: tools/bake-lave-station.ps1 (Windows PowerShell 5.1).
- Exactly 340×168, 32 colours, byte indices; transparency index 255 for sprites. 399,840 plate bytes + 24,576 sprite bytes + 128-byte palette. No runtime PNG decoding or per-room allocation.
- Shared recipe table owns screen/landmark/person rectangles; rendered prop IDs also supply hotspot labels/descriptions.
- Seed = system + hub + room. Economy selects prop families and material tints. No simulation RNG consumption.
- All 256 systems × 3 hub variants × 7 rooms share the kit. Reorte's approved Arrivals and Second Shift remain authored overrides.
- Bounded screen activity, bar steam and distant traffic use presentation time, so they animate while docked.
- This is the reusable foundation, **not 1,792 individually authored unique interiors**. Seven shared architectural plates still contain fixed scenery; wider architectural/window/economy-specific kits and further local stories are the next art/content expansion.

## Persistence

V19 appends 256 × HUB_COUNT little-endian u32 words before CRC. Each word holds manifest state (bits 0–1), Lave story stage (2–5), visited rooms (8–14), generic survey tip claimed (16), clinic treatment claimed (17). Other bits currently unused; reserved upper bits and invalid stages rejected.

Old shared manifest high bits migrate once when visiting the matching hub; low gift bits preserved. Old save layouts remain loadable. Writes retain existing atomic validation/backup behavior. V19 cannot be opened by an older build.

## Audit / preservation

Kept existing station input, fixed seven-room graph, regular services, named Reorte bar, tutorial route, existing mission board and planetary scans. New story is optional and separate from main/Guild campaigns; Berth Six gets its own Mission Log/Tracked Mission entry. Tutorial keeps its original Chandler and cast, with no Lave story override during training.

The audit found and fixed shared manifest progress being lost between hubs, repeatable unearned survey rewards, clipped dialogue, mismatched 12-pixel highlights versus 8-pixel text-grid positions, hover replacing descriptions, and station animation using a simulation clock that stops while docked.

## Tests / limitations

Automated checks cover all 5,376 identity/room combinations for deterministic seeds and bounded labelled hotspots, graph reachability, actual conversation/manifest input, each story checkpoint save/load, one-time rewards, local-vs-remote survey records, service return, legacy manifest migration, V7/V14/V18 import and V19 invalid-state rejection. Native room and dialogue captures are generated by the smoke suite; render cost is measured for all seven rooms.

Full game/input/steering/radio/performance regression reports are recorded in CLAUDE-HANDOFF.md after the final build.

No physical PSP test was possible here. Existing physical-device landing shutdown reports remain a separate unverified risk for the survey trip. New audio is procedural ambience plus the existing music synth; there is no newly recorded soundtrack. Subjective volume/balance needs PSP listening. Full 256-system uniqueness and hardware-perfect behavior are not claimed.
