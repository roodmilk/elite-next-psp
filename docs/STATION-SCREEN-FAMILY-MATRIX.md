# Station screen family matrix

| Screen | Visual family | Hero composition | Fixed runtime elements | Current art status |
|---|---|---|---|---|
| Arrivals | Freight | ribbed concourse, arrival board, freighter window | options, hotspots, SHIP, feedback | native room asset delivered; dispatch/capture pending |
| Canteen/Bar | Freight or Prospectors' rest | Second Shift counter, people, window, lamp | NPC truth, choices, SHIP, job/dice state | Second Shift native room asset delivered separately; interaction integration pending |
| Market | Merchant salon | ledger rotunda, counter, layered displays | item names/prices, selection, purchase/sell truth | token/layout contract only |
| Shipyard/Outfitting | Frontier or Merchant | gantry, work lights, hull silhouette, parts racks | actual fitted ship, category tabs, price/fit rules | existing outfitting implementation; style migration planned |
| Mission Board | Research or Freight | pinned route board, clerk, map window | authoritative offer/acceptance/capacity text | token/layout contract only |
| GalNet | Research lounge | observation window, terminal glow, seated operator | real article/rumour data, page controls | token/layout contract only |

All rows use the shared native safe bands, palette roles and family modules. A row marked “contract only” is not complete art and must not be reported as runtime coverage.
