# ELITE: NEXT v0.7 release plan

This plan turns the design bible into staged, testable releases. The internal
`2.5.x` build number is separate from these product milestones.

## v0.5 — Lave showcase

The Lave route is the first complete quality slice: launch, local traffic,
docking, station walking, canteen/bar conversation, a mission, market and
outfitting, planetary approach, landing, EVA, return, save, reload and resume.
It exits only when the current EBOOT has native 480x272 normal/contrast
captures plus current-hash boot, input, station, planet, audio and performance
reports. Existing hotspots and save contracts must remain unchanged.

## v0.6 — polish and reliability

The team improves existing systems rather than adding breadth: bars and rooms,
planet/sun art, space backgrounds, flight FX, ship presentation, dialogue,
radio, transitions, wording, clipping, memory and recovery. Each change needs a
native proof frame, a regression check and a current build identity.

## v0.7 — Galaxy Beta

The polished Lave standard expands to multiple hubs and systems. Beta gates
cover route planning, danger/security, factions, traffic/freighters, markets,
mission jobs, ship roles, story progress, save migration, and long-session
performance. The 256-system chart remains bounded and offline; no infinite
terrain or unloaded-world simulation is added.

## Release rules

- A feature marked implemented but lacking current runtime evidence is
  `BLOCKED`, not complete.
- Art is authored for the PSP's 480x272 framebuffer and must preserve existing
  selectors, hotspots, save state and interaction contracts.
- Stale emulator reports never certify a newer EBOOT.
- No milestone is complete while a known progression blocker, save-loss path,
  or unbounded allocation remains.
