# Reusable Element Kit freeze

Frozen metadata handoff for PSP UI & Art Reusable Element Kit.

The manifest freezes element IDs, native sizes, pivots, hitboxes, contrast
behavior, authored/procedural flags and measured packed 4-bit costs. The six
assembled native frames are layout/contrast evidence for Freight, Prospector
and Research; they are not runtime captures and do not authorize composer
wiring.

No duplicate people or doors: authored scenes own their people and route
anchors. A procedural room must not place a second person or door over an
authored role/anchor. Procedural variation may select only declared props,
depth variants and stable content channels.

This freeze changes kit metadata, documentation and preview assets only. It
does not change station runtime, selector/version, saves, gameplay, audio or
the separate shared footer candidate. PSP UI & Art Procedural Room Composer may reference IDs after Systems freezes the
selector/generator hash and Team reserves the composer include/dispatch hunk.
